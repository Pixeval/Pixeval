Краткое руководство приводит примеры наиболее распространённых вариантов поиска.

## Простой поиск

| Синтаксис                                 | Значение                                                                                           |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| abc                                       | Поиск работ, в названии которых есть abc                                                           |
| #abc                                      | Поиск работ, у которых есть тег abc                                                                |
| Поиск работ конкретного автора            | Поиск работ конкретного автора                                                                     |
| -r18g                                     | Исключить контент R18G                                                                             |
| +gif                                      | Показать GIF/Ugoira (доступные ограничения: r18, r18g, gif, ai) |
| l:100-200                 | Поиск работ, имеющих от 100 до 200 закладок                                                        |
| s:MM-dd                   | Поиск работ, опубликованных не ранее MM-dd                                                         |
| e:yyyy-MM-dd              | Поиск работ, опубликованных не позднее yyyy-MM-dd                                                  |
| r:1.2-3/2 | Соотношение сторон от 1.2 до 3/2 (не применяется к новеллам)    |

## Составной поиск

| Синтаксис                         | Значение                                                      |
| --------------------------------- | ------------------------------------------------------------- |
| abc #def                          | Название содержит abc И тег содержит def                      |
| !#def                             | Тег НЕ содержит def                                           |
| "ab c"                            | Поиск ключевого слова с пробелами ("ab c") |
| abc$ "ab c$"                      | Точный поиск ключевых слов abc и "ab c"                       |
| (or abc$ #def) | Название точно совпадает с abc ИЛИ тег содержит def           |
