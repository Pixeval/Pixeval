## Адрес подключения

Адрес подключения по умолчанию:

```text
http://127.0.0.1:52163/mcp
```

Если вы изменили порт, замените `52163` на ваш порт.

Pixeval прослушивает только `127.0.0.1` (локальный адрес).Pixeval прослушивает только `127.0.0.1` (локальный адрес).ИИ-инструменты на том же компьютере смогут подключиться к Pixeval, но устройства из локальной сети не смогут получить прямой доступ.

> [!INFO]
> Перед подключением убедитесь:
>
> - Pixeval запущен.
> - - «Включить сервер MCP»: при включении Pixeval запустит локальную службу MCP в десктопном приложении.
> - ИИ-инструмент и Pixeval запущены на одном компьютере.
> - Порт не занят другими программами.
> - Инструменты, вызывающие API Pixiv, обычно требуют, чтобы в Pixeval был выполнен вход.

## Настройка ИИ-инструментов

MCP в Pixeval — это Streamable HTTP MCP внутри процесса GUI.

```text
http://127.0.0.1:52163/mcp
```

Если у инструмента есть графический интерфейс, выберите добавление сервера MCP, укажите тип `HTTP`, `Streamable HTTP` или `Remote`, имя `Pixeval`, а в качестве URL укажите адрес выше.

Ниже приведены примеры конфигураций для различных форматов файлов.Ниже приведены примеры конфигураций для различных форматов файлов.

Если инструмент использует конфигурационный файл вроде `mcp.json` и поддерживает HTTP MCP, можно использовать следующую запись:

```json
{
  "servers": {
    "pixeval": {
      "type": "http",
      "url": "http://127.0.0.1:52163/mcp"
    }
  }
}
```

Некоторые инструменты используют имя ключа `mcpServers`:

```json
{
  "mcpServers": {
    "pixeval": {
      "type": "http",
      "url": "http://127.0.0.1:52163/mcp"
    }
  }
}
```

Если конфигурация TOML поддерживает HTTP URL, можно использовать такую форму:

```toml
[mcp_servers.pixeval]
type = "http"
url = "http://127.0.0.1:52163/mcp"
```

Если ИИ-инструмент поддерживает только `stdio` MCP (то есть запуск исполняемого файла в качестве сервера MCP), он не сможет напрямую подключиться к встроенному HTTP MCP Pixeval.Pixeval не предоставляет отдельный exe для stdio.Pixeval не предоставляет отдельный exe для stdio.

## Разрешения и безопасность

Права доступа Pixeval MCP совпадают с правами запущенного Pixeval:

- MCP использует текущий вошедший аккаунт Pixeval и текущие сетевые настройки.
- MCP не возвращает клиенту конфиденциальную информацию: refresh token, cookie, адреса прокси, значения настроек расширений.
- - Инструменты записи по умолчанию отключены.При их включении ИИ может выполнять действия от вашего имени. Подключайте только доверенных клиентов.
- Pixeval прослушивает только локальный адрес и не транслируется в сеть.
- «Макс. размер бинарных ресурсов MCP (МБ)»: ограничение размера возвращаемых клиенту миниатюр и бинарных файлов.Этот лимит ограничивает объем данных, возвращаемых сервером Pixeval MCP.
