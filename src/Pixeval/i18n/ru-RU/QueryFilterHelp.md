Полное руководство в основном описывает синтаксис с примерами всех способов составления поисковых запросов.

## Синтаксис выражений фильтрации

| Синтаксис                                                                          | Значение                                                      |
| ---------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| [str]                          | Заголовок                                                     |
| #[str]                         | Тег                                                           |
| @[str]            | Автор                                                         |
| +[const]                       | Включающее ограничение                                        |
| -[const]                       | Исключающее ограничение                                       |
| l:[int-range]  | Фильтр по числу закладок                                      |
| r:[frac-range] | Фильтр по соотношению сторон (иллюстрации) |
| s:[date]       | Начальная дата публикации                                     |
| e:[date]       | Конечная дата публикации                                      |

## Синтаксис значений

### [str] Строка

| Синтаксис | Значение                             |
| --------- | ------------------------------------ |
| abc       | Обычная строка                       |
| "ab# c"   | Строка с пробелами или спецсимволами |
| abc$      | Строка для точного совпадения        |
| "ab c$"   | Строка с пробелами или спецсимволами |

### [num] Число

| Синтаксис | Значение      |
| --------- | ------------- |
| 12345     | Обычное число |

### [const] Ограничение

| Синтаксис | Значение                                      |
| --------- | --------------------------------------------- |
| r18       | Контент R18 (включая R18G) |
| r18g      | Контент R18G                                  |
| gif       | Анимация (Ugoira/GIF)      |
| ai        | Контент, сгенерированный ИИ                   |

### [int-range] Диапазон/множество целых чисел

| Синтаксис | Значение               |
| --------- | ---------------------- |
| 2-        | Больше или равно 2     |
| -3        | Меньше или равно 3     |
| 2-3       | От 2 до 3 включительно |

### [frac-range] Диапазон вещественных чисел

| Синтаксис               | Значение                                   |
| ----------------------- | ------------------------------------------ |
| 2-                      | Больше или равно 2                         |
| -1.5    | Меньше или равно 1.5       |
| -1/2                    | Меньше или равно 1/2                       |
| 1/2-3                   | От 1/2 до 3 включительно                   |
| 0.3-1/2 | От 0.3 до 1/2 включительно |

### [date] Дата

| Синтаксис                                  | Значение                   |
| ------------------------------------------ | -------------------------- |
| MM-dd                                      | День и месяц текущего года |
| MM.dd                      | День и месяц текущего года |
| yyyy-MM-dd                                 | День, месяц и год          |
| yyyy.MM.dd | День, месяц и год          |

> > Разделители "." и "-" взаимозаменяемы

## Последовательности

| Синтаксис                                                                                            | Значение                           |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------- |
| !\<segment>                                                                                         | Отрицание (NOT) |
| (and \<segment> \<segment> ...) | Логическое И                       |
| (or \<segment> \<segment> ...)  | Логическое ИЛИ                     |

> > Режимы можно свободно вкладывать друг в друга. Выражение верхнего уровня по умолчанию использует режим И.
